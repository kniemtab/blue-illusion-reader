# The Blue Illusion — ฉบับสรุปภาษาไทย

เว็บอ่านสรุป 16 บทและบทพิเศษ พร้อมภาพประกอบ AI 17 ภาพ ภาพปก สารบัญ โหมดมืด ปรับขนาดตัวอักษร และบันทึกตำแหน่งอ่าน

## เปิด GitHub Pages

ไปที่ Settings → Pages เลือก Deploy from a branch แล้วเลือก main และ / (root) จากนั้น Save

หลังเผยแพร่ เว็บไซต์จะอยู่ที่ https://kniemtab.github.io/blue-illusion-reader/

## ไฟล์

เว็บไซต์ HTML/CSS/JavaScript แบบ static ไม่ต้อง build ไฟล์ทั้งหมดอยู่ที่ root และภาพอยู่ใน images/

เนื้อหาเป็นการสรุปและอภิปรายหนังสือ ไม่ใช่คำแนะนำทางการแพทย์ ภาพประกอบ AI เป็นภาพเชิงแนวคิด ไม่ใช่หลักฐานเหตุการณ์จริง เครดิตและข้อสังเกตอยู่ในหน้าเว็บไซต์
